## 📖 1. Project Overview & Motivation

Modern devices are engineered to maximize screen time, capture attention, and keep users endlessly scrolling indoors. **GreenBuddy AI** turns this dynamic upside-down. 

Designed for students, developers, and everyday people, GreenBuddy AI is an offline-first companion that treats screens as the **shortest part of the experience**:
1. Select your available time (5–60 minutes) and outdoor setting (Garden, Park, Balcony, Neighborhood).
2. Generate a personalized, mindful nature quest powered by **open-weight Gemma 3 (1B)**.
3. Read the three actionable steps in 15 seconds.
4. Step outside, pocket your device, and reconnect with real trees, soil, weather, and urban wildlife.

GreenBuddy AI operates with **strict privacy**: all streaks and minutes are self-reported locally in your browser. There is **zero GPS tracking**, zero ad telemetry, and zero mandatory account sign-in.

## ✨ 3. Key Features

- **Gemma 3 Open-Weight Integration**: True model inference with JSON schema constraints via local Ollama (`gemma3:1b`) or hosted Gemma endpoints.
- **Strict Nature & Human Safety Guardrails**: AI prompt constraints and server-side validation strictly ban hazardous suggestions (never ingest wild mushrooms/plants, never touch unknown wildlife, never trespass or damage plants).
- **Offline Progressive Web App (PWA)**: Includes manifest, service workers, icon sets, offline caching, and native in-app install buttons.
- **Three-Tier Fallback Transparency**: Clearly displays whether a quest was generated by `Gemma + Ollama`, `Gemma Hosted`, or the `Built-in Curated Library`.
- **Active Outdoor Companion Mode**: Minimalist high-contrast stopwatch that minimizes screen distraction while outdoors.
- **Self-Reported Progress & Streaks**: Tracks completed quests, fresh air minutes, calendar-based day streaks, and 10 unlockable achievements without accounts or GPS tracking.
- **Diagnostics Console**: One-click runtime health check showing Ollama connectivity, model availability, and ping status.

---

## 🧠 4. Why Open-Weight AI (Gemma) Matters

1. **Edge Autonomy Away from Connectivity**: The outdoors doesn't have reliable 5G. Gemma 3 1B runs efficiently on modest consumer CPUs and edge devices through Ollama, allowing real AI generation deep in wooded trails or remote gardens.
2. **Absolute Privacy**: No personal habits or journal reflections are shipped to third-party model providers.
3. **No Vendor Lock-In**: Open weights ensure long-term durability for open-source initiatives.
4. **Reproducibility**: Anyone can pull `gemma3:1b` and inspect the prompt engineering directly.

## ⚙️ 5. Local Setup Instructions

### Prerequisites
- [Node.js](https://nodejs.org/) v20+
- [Ollama](https://ollama.com/) (for local Gemma 3 inference)

### Step 1: Install and Run Gemma 3 via Ollama
In your terminal, pull and run the Gemma 3 1B model:
```bash
ollama run gemma3:1b
```
*(Ollama will start its HTTP daemon at `http://127.0.0.1:11434`)*

### Step 2: Clone and Install GreenBuddy AI
```bash
git clone https://github.com/hacktoberfest2026/greenbuddy-ai.git
cd greenbuddy-ai
npm install
```

### Step 3: Configure Environment
Copy the example configuration:
```bash
cp .env.example .env
```
Default `.env` settings:
```env
PORT=3000
OLLAMA_BASE_URL="http://127.0.0.1:11434"
GEMMA_MODEL="gemma3:1b"
HOSTED_GEMMA_URL=""
HOSTED_GEMMA_API_KEY=""
HOSTED_GEMMA_MODEL="gemma-3-1b-it"
```

### Step 4: Start the Full-Stack Application
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser. The header indicator will turn green, indicating **Gemma 3 (Ollama Local)** is active!

## 🌐 6. Online Deployment Instructions

GreenBuddy AI is designed so the frontend and backend can be hosted cleanly:

### Standalone Production Service (Express + Built Frontend)
```bash
npm run build
npm start
```

### Hosting Considerations for Ollama
- A hosted web service in the cloud cannot reach a user's private laptop `127.0.0.1:11434` due to browser sandbox security.
- To enable live Gemma inference in cloud deployments, configure a hosted inference endpoint in `.env`:
  ```env
  HOSTED_GEMMA_URL="https://your-gemma-endpoint.com/v1"
  HOSTED_GEMMA_API_KEY="your-api-key"
  HOSTED_GEMMA_MODEL="google/gemma-3-1b-it"
  ```
- If neither Ollama nor a hosted endpoint is configured, GreenBuddy AI gracefully operates using its pre-cached 24-quest offline library, clearly labeled in the UI.

## 📱 7. Offline Testing Procedure

1. Launch GreenBuddy AI in Chrome, Edge, or Safari.
2. In DevTools, open the **Application** tab and verify the Service Worker is registered.
3. In DevTools **Network** tab, check the **Offline** box (or disconnect Wi-Fi).
4. Refresh the page: the application loads instantly from cached assets.
5. Generate a quest: the system seamlessly serves from the built-in nature library and shows the amber **Offline Mode** indicator.
6. Check off quest steps, record your self-reported minutes, and observe the streak and badge counters update.

## 🛡️ 8. Safety & Environmental Rules

GreenBuddy AI strictly adheres to the following principles:
- **Zero Foraging/Ingestion**: Never encourages eating, tasting, or foraging wild vegetation or mushrooms.
- **Wildlife Buffers**: Always observe birds, pollinators, and insects from a respectful buffer. Never attempt to handle or trap creatures.
- **Leave No Trace**: Never pick living flowers, break tree limbs, or trample fragile ground cover.
- **Situational Awareness**: Reminds users to maintain vigilance regarding street traffic, cyclists, and changing weather.

---

## ⚠️ 9. Known Limitations

- **Browser Sandbox & Localhost**: Web applications hosted on public URLs cannot query a user's private `127.0.0.1` Ollama port without running the web app locally or using a configured hosted endpoint.
- **Self-Reported Data**: To preserve privacy, outdoor minutes and streak metrics rely entirely on user honor; no GPS telemetry is collected.
